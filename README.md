# Home Energy Tracker

| Folder | What's inside |
| --- | --- |
| [`server/`](server/README.md) | Spring Boot microservices, API gateway, Docker Compose infrastructure |
| [`client/`](client/README.md) | Angular web frontend (bun) |

Quick start: bring up the backend from `server/`, then `cd client && bun install && bun run start`. The client's README covers the one-time Keycloak client setup.
